# 专利文档工具箱

用于 Microsoft Word 的 VBA 工具集，帮助处理中文专利文档中的重复操作：补充附图标记、转换已有权利要求的固定表述、同步页眉案号，以及清理文本格式。

工具按预设规则处理已有文本，技术方案、申请文件内容和最终表述由使用者编写与确认。

## 功能

| 工具 | 处理范围 | 作用 |
| --- | --- | --- |
| 权利要求标号 | 选中的权利要求 | 根据文档中的附图标记说明，为部件名称补充括号标记，如 `壳体` → `壳体（1）` |
| 具体实施方式标号 | 选中的具体实施方式 | 根据同一份附图标记说明补充标记，如 `壳体` → `壳体1` |
| 权利要求转发明内容 | 选中的权利要求段落 | 按规则处理编号、引用和固定用语，转换为“本发明提供…”、“在一些实施例中…”等表述 |
| 页眉双模式同步 | 文档各节的页眉第一行 | 从文件名提取案号，或以首页页眉第一行为准进行同步 |
| 一键改格式：全文 | 文档正文 | 清理 Markdown 标记、部分不可见字符和标点，统一中英文字体；运行时关闭修订 |
| 一键改格式：选区 | 当前选区 | 对选中文本进行格式清理；可在开启修订时使用，但部分操作不记录修订 |

格式工具当前将中文字体设为楷体，西文字体设为 Times New Roman。运行前请确认这符合所用文档模板的要求。

## 版本与运行环境

当前仓库提供两种形态：

- **源码版**：包含统一的“专利文档工具箱”面板，需要导入 Word 测试模板后使用。
- **[现有模板](dist/PatentTools.dotm)**：保留六个独立功能宏，尚未包含源码中的工具面板和新入口名称。

目前以 **Windows 桌面版 Microsoft Word** 为运行环境。源码中的部分功能依赖 `Scripting.Dictionary` 和 `VBScript.RegExp`，尚不具备完整的 Mac 兼容实现。

## 使用现有模板

1. 下载 `dist/PatentTools.dotm`，保存到本地。
2. 在 Word 的“开发工具 → 文档模板 → 模板和加载项”中添加并勾选该模板，按所在环境的宏安全策略启用。
3. 打开待处理的文档并保存副本。使用标号、文本转换或选区格式工具时，先选中目标文本。
4. 在“开发工具 → 宏”中选择对应功能并运行。
5. 检查处理结果，再决定是否保留修改。

现有模板中的格式工具名称分别是 `一键改格式_全文修改_不兼容修订` 和 `一键改格式_选中部分修改_兼容修订`。

## 常用操作

### 补充附图标记

文档中需要有“附图标记说明如下”及对应的名称、标记，例如：

```text
附图标记说明如下：
1 壳体；2 支撑架；3 驱动机构。
```

选中需要处理的权利要求或具体实施方式，再运行对应标号工具。名称应与附图标记说明一致；运行后重点检查名称相互包含、已有标记和同名部件等位置。

### 转换权利要求表述

先将需要转换的权利要求复制到目标位置，再选中这些段落运行工具。**转换会直接修改选区中的原文**。

工具按固定规则删除或替换权利要求编号、附图标记、“所述”、引用语句和“其特征在于”等用语。转换后需要通读，重点核对引用关系、方法步骤顺序和技术含义。

### 同步页眉案号

运行“页眉双模式同步”后，按弹窗选择：

- **是**：从已保存文档的文件名提取案号，更新各节页眉第一行。
- **否**：以首页页眉第一行为准，同步各节页眉。
- **取消**：退出。

处理后检查分节处，以及启用了“首页不同”或“奇偶页不同”的页眉。

### 清理格式

局部处理时使用选区工具；需要统一正文格式时使用全文工具。公式、化学式、网址、英文内容中的标点和符号可能具有实际含义，应在处理后核对。

全文工具在运行时关闭修订，完成后恢复原状态。选区工具在处理部分引号和反引号时也会临时关闭修订，因此“兼容修订”不代表每一处修改都会留下痕迹。必须完整保留修改记录的文档，不宜直接使用这两项格式工具。

## 从源码使用工具面板

仓库中的源码以 UTF-8 保存。导入中文 Windows 的 VBA 编辑器前，在仓库根目录运行：

```powershell
.\scripts\prepare_vbe_import.ps1
```

脚本会将源码转换为代码页 936 的导入副本，输出到 `build/vbe-import/`。

1. 新建一份用于测试的 Word 启用宏的模板（`.dotm`）。
2. 打开 VBA 编辑器，选中该模板的工程，导入 `build/vbe-import/` 中的全部 `.bas` 文件和 `frmPatentToolbox.frm`。`ThisDocument.cls` 是文档类的导出记录，当前不含业务代码，无需作为普通类模块导入。
3. 执行“调试 → 编译 VBAProject”，保存模板。
4. 加载模板，在 Word 的宏列表中运行 `专利文档工具箱`，通过面板选择功能。
5. 在文档副本中验证六项功能后，再用于日常文档。

更新过旧版源码、且绑定了旧入口 `专利撰写工具箱` 的快捷键或工具栏按钮，需要重新绑定到 `专利文档工具箱`。

编码转换脚本只准备导入文件，不会自动生成或更新 `dist/PatentTools.dotm`。当前仓库也未提供覆盖各 Word 版本的兼容性测试结果。
